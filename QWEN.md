UI для сервиса по генерации карточек для маркетплейсов таких как Ozon и Wildberries

Как работает:
1. Пользователь загружает изображение товара
2. Выбирает одну из 3-х концепций
3. Нажимает сгенерировать карточку
4. Редактирует текст на карточке

Используемый стек:
1. React
2. Typescript
3. tanstack start
4. chadcn
5. tailwind
6. vite
7. eslint
8. prettier

Нужно использовать компоненты из chadcn, скачивая так:
```bash
pnpm dlx shadcn@latest add button
```

Страницы:
1. src/routes/index.tsx - главная страница, на которой описано что представляет из себя сервис с примерами функционала
